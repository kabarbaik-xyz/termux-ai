# Training 5.1 — Task Decomposition (the new architecture skill)
Audience: PM + leads. Half-day + 2 coached sprints.
1. Outcome phrasing: stories name a demoable outcome, never a task list.
2. AC discipline: given/when/then, ≤5, each verb QA can verify; write the AC BEFORE any prompt to AI.
3. Size gates: ≤3 days / PR ≤400 lines — bigger = decomposition failure, practice splits on real backlog items.
4. Files-touched hint: guide the AI's blast radius without constraining.
5. Drill: take 3 real stories, decompose, have AI implement one AC-set, review where the story leaked ambiguity → fix the story, not the code.
