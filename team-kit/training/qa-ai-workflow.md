# Training 5.3 — QA AI Workflow (2-week ramp, pairs with the pilot)
Week 1: run `qa` + `frontend-tester` daily on real screens; learn to read generated specs — spotting weak assertions (asserting text exists vs asserting behavior), missing states, hardcoded waits. 
Week 2: own the loop — states matrix → generate → review → run → report; introduce the traceability table in stand-up. 
Graduation: QA independently produces a release's coverage map + runnable suite; devs consume their bar as the merge gate.
