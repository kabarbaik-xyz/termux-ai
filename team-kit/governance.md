# Governance & Measurement (Phase 6)
## Metrics (from day 1 of pilot)
- Cycle time (story start → merged) · review-rework rate (% PRs needing >1 round) · defect escape rate (post-merge P0/P1) · AI-assisted share of PRs (self-reported tag) · states-matrix coverage %.
No vanity metrics. Each has an owner (PM/leads/DevOps) and appears in the month-2 retro.
## Standards changes
AGENTS.md / skills / templates change ONLY via PR approved by the standards owner (Phase 0.6). Skills follow the two-tier rule + schema; a PR without reads/writes headers is rejected.
## Month-2 retro agenda
Metrics review → prune unused skills → strengthen weak gates → confidentiality incidents/near-misses → scale decision (pilot 2-3 devs → whole team) with explicit go/no-go criteria.
## Scale checklist
Gates green 4 consecutive weeks · rework <15% · QA bar enforced on 100% merges · retro actions closed → scale.
