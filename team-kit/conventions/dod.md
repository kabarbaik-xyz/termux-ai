# Definition of Done (checkable, per layer)
Story: AC all pass (QA-verifiable) · all 5 states · tests included · PR ≤400 lines · review checklist green.
Epic: demoable increment · traceability matrix updated (US→SC→component→test).
Release: CI green · ux-audit clean (no orphan screens/tokens violations) · docs synced (PRD/TSD drift = zero or ticketed) · changelog written.
If CI can't verify it, it is not done — for AI code OR human code.
