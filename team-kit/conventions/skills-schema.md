# Skills Schema (applies to EVERY skill, both tiers)
Header line right after frontmatter:
`> **Reads:** <docs/phases/inputs> · **Writes:** <artifacts/IDs>`
- Reads/Writes name DOCUMENTS and IDs (discovery.md, US-xxx, tokens.json), never vibes.
- Tier rule: Tier-1 (generic: fullstack, brainstorm, qa, frontend-tester, reverse-engineer, review, commit) never references a specific stack; Tier-2 (house) always does.
- A skill without declared I/O is not reviewable — PRs reject it.
